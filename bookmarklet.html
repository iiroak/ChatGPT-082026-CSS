Extractor de CSS de ChatGPT

  1. Arrastra este botón a la barra de marcadores: Extraer CSS de ChatGPT
  2. Abre chatgpt.com logueado, con la UI en el tema y estado que quieras capturar.
  3. Pulsa el marcador. Se descargará un archivo chatgpt-css-YYYY-MM-DD.css con todos los bundles concatenados.
  4. Guarda ese archivo en ~/projects/GPT-Style/ y avísame.

Nota: si el aviso final dice que todas fallaron, Cloudflare/CDN está bloqueando CORS; en ese caso copiame las URLs (F12 → Network → filtro CSS) y las bajo yo desde el servidor.
